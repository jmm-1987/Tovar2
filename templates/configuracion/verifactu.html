🔐 Información sobre API Verifactu

¿Qué es Verifactu?

Verifactu es una plataforma que permite la comunicación de facturas electrónicas con la Agencia Tributaria española, cumpliendo con la normativa de facturación electrónica.

Configuración

⚠️ Funcionalidad temporalmente desactivada: La integración con Verifactu está desactivada. El código está comentado y puede restaurarse más adelante si es necesario.

La configuración de la API Verifactu se realiza mediante la variable de entorno VERIFACTU_TOKEN en el archivo .env o en las variables de entorno del servidor.

VERIFACTU_TOKEN=tu_token_aqui

Nota: El código de Verifactu está comentado en el código fuente y puede restaurarse descomentando las secciones marcadas con # CÓDIGO VERIFACTU COMENTADO - Se puede restaurar más adelante

Tipos de Factura

  • F1 - Factura Completa: Se utiliza para facturas formales. Requiere NIF y nombre del cliente.
  • F2 - Factura Simplificada: Se utiliza para tickets de tienda. No requiere NIF ni nombre del cliente.

Endpoint de la API

La aplicación utiliza el siguiente endpoint para comunicar las facturas:

https://api.verifacti.com/verifactu/create

Campos Requeridos

Para Facturas F1:

  • Serie y número
  • Fecha de expedición
  • Tipo de factura (F1)
  • NIF del cliente
  • Nombre del cliente
  • Líneas con base imponible, tipo impositivo e IVA
  • Importe total

Para Facturas F2 (Tickets):

  • Serie y número
  • Fecha de expedición
  • Tipo de factura (F2)
  • Líneas con base imponible, tipo impositivo e IVA
  • Importe total
  • NO se incluyen NIF ni nombre del cliente

Estado de las Facturas

  • pendiente: Factura creada pero aún no comunicada
  • enviado: Factura comunicada a Verifactu
  • confirmado: Factura confirmada por Verifactu
  • error: Error en la comunicación
